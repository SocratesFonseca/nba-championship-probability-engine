# NBA Championship Probability Engine

A simple project for estimating NBA championship probabilities.

## What It Does

This app has a FastAPI backend and a React frontend. The backend is set up for prediction data, and the frontend gives the project a basic interface.

## Run It

Backend:

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

## Tech Used

- Python
- FastAPI
- React
- Vite
- SQLAlchemy
